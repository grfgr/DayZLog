# Публикация PvPLog в Мастерской Steam

Картинка для превью: `workshop/preview.jpg` (1024×1024, ~180 КБ; лимит Steam — 1 МБ).
Перегенерировать её: `python3 workshop/make_preview.py workshop` (нужен Pillow).

## 1. Папка для загрузки

Публикуется не исходник, а готовая папка мода. Соберите её отдельно, например:
```
C:\DayZMods\Upload\@PvPLog\
    Addons\PvPLog.pbo      ← собранный Addon Builder'ом
    mod.cpp                ← скопировать из исходника PvPLog\mod.cpp
```
Больше в этой папке ничего быть не должно: всё, что в ней лежит, уйдёт в Мастерскую.

`mod.cpp` лежит в корне `@PvPLog`, а не внутри PBO: по нему лаунчер показывает название и автора мода.

### Подпись (необязательно)
PvPLog — серверный мод, клиенты его не загружают, поэтому ключ ему **не нужен**. Если всё же хотите подписать:
1. DayZ Tools → **DS Utils** → создать ключ (например `ZloyDed`). Получатся `ZloyDed.biprivatekey` (никому не отдавать!) и `ZloyDed.bikey`.
2. В Addon Builder поставить **Sign**, а в Options указать **Path to private key file**.
3. `ZloyDed.bikey` положить в `@PvPLog\keys\`.

## 2. Publisher

1. Steam → Библиотека → Инструменты → **DayZ Tools** → **Publisher**.
2. Заполните поля:
   - **Title**: `PvPLog — PvP hits & kills logger (VPP)`;
   - **Description**: см. шаблон ниже;
   - **Preview image**: `workshop\preview.jpg`;
   - **Content folder** (папка с содержимым): `C:\DayZMods\Upload\@PvPLog`;
   - **Tags**: `Server`, `Scripts` (что есть в списке);
   - **Visibility**: сначала **Private** или **Friends only**: проверить, что всё скачивается, потом переключить на **Public**;
   - **Change note**: `Первая версия`.
3. Нажмите **Publish**. Steam выдаст ID предмета и ссылку на страницу.
4. Если Steam пишет, что предмет не виден, пока вы не приняли **Соглашение подписчика Steam**, откройте страницу предмета и примите его по ссылке вверху.

## 3. Страница в Мастерской

На странице предмета (в браузере или Steam):
- **Add/Remove Required Items** → добавьте **VPPAdminTools** и **Community Framework**. Тогда Steam сам предложит подписаться на них;
- при желании добавьте скриншоты Discord-сообщений и строк лога.

## 4. Обновление

1. Пересоберите PBO и замените `Addons\PvPLog.pbo` в папке загрузки.
2. Publisher → выберите ваш опубликованный предмет из списка (или по ID).
3. Напишите **Change note** (что поменялось) → **Publish/Update**.

## 5. Как поставить мод с Мастерской на сервер

Это серверный мод, поэтому:
1. Подписаться, запустить DayZ Launcher, чтобы мод скачался в `DayZ\!Workshop\@PvPLog` (или скачать через SteamCMD на хостинге: `workshop_download_item 221100 <ID>`).
2. Скопировать `@PvPLog` в папку сервера.
3. Подключить через `-servermod=@PvPLog` (не через `-mod`).
4. Настроить `profiles\PvPLog\settings.json`.

## Шаблон описания (Steam BBCode)

```
[h1]PvPLog — логи PvP для сервера[/h1]

Серверный мод: пишет каждое PvP-попадание и убийство.

[h2]Что логируется[/h2]
[list]
[*] кто и кому (ник + Steam64 ID)
[*] куда попал (голова, торс, руки, ноги)
[*] с чего: оружие, патрон, способ (огнестрел, ближний бой, граната, ловушка, транспорт)
[*] урон, остаток HP, дистанция
[*] при убийстве — координаты убийцы и жертвы
[*] «косвенные» убийства: жертва истекла кровью после выстрела
[/list]

[h2]Куда[/h2]
[list]
[*] файлы profiles/PvPLog/logs (текст + JSONL), ротация по дням
[*] Discord-вебхук (только убийства)
[*] VPPAdminTools: команда /pvplog для админов (право PvPLog:ChatHistory)
[/list]

[h2]Установка[/h2]
Только на сервер: [b]-servermod=@PvPLog[/b]. Клиентам ставить не нужно.
Требуется VPPAdminTools.
Настройки: profiles/PvPLog/settings.json (создаётся при первом запуске).

Автор: ZloyDed.dll
```
