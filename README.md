# PvPLog: логи PvP для DayZ (VPPAdminTools)

Серверный мод. Он пишет каждое PvP-попадание и каждое убийство:
- **кто** нанёс урон и **кому** (ник + Steam64 ID);
- **куда** попал (голова, торс, руки, ноги…);
- **во сколько** (время сервера);
- **с чего** (оружие, патрон, способ: огнестрел, ближний бой, взрыв, ловушка, транспорт);
- **сколько** урона (HP, кровь, шок) и сколько HP осталось;
- **дистанция** и **координаты** обоих игроков. При убийстве пишутся координаты убийцы и жертвы.

Куда уходят логи:
1. файлы `$profile:PvPLog/logs/PvP_ГГГГ-ММ-ДД.log` (текст) и `.jsonl` (JSON по строке, для парсеров и сайтов);
2. Discord-вебхук: **только убийства** (попадания пишутся только в файлы);
3. **VPPAdminTools**: чат-команда `/pvplog` с правом, которое выдаётся в меню VPP.

## Зависимости

- **VPPAdminTools** (обязательно, через `requiredAddons`);
- Community Framework стоит на сервере для VPP, сам мод от него не зависит.

## Сборка и установка

1. Соберите папку `PvPLog/` в PBO через **DayZ Tools → Addon Builder** (или pboProject):
   - Source: `.../PvPLog`
   - Prefix: `PvPLog`
   - на выходе: `@PvPLog/Addons/PvPLog.pbo`
2. Положите `@PvPLog` в папку сервера.
3. Запускайте как **серверный** мод: VPP и CF обычно в `-mod`, PvPLog в `-servermod`:
   ```
   -mod=@CF;@VPPAdminTools -servermod=@PvPLog
   ```
   Клиентам мод **не нужен**, подписывать ключом не обязательно.
4. При первом запуске появится `profiles/PvPLog/settings.json`.

## Настройки: `profiles/PvPLog/settings.json`

| Ключ | По умолчанию | Что делает |
|---|---|---|
| `LogHits` | `1` | логировать попадания |
| `LogKills` | `1` | логировать убийства |
| `WriteTextLog` | `1` | писать `.log` |
| `WriteJsonLog` | `1` | писать `.jsonl` |
| `LogRetentionDays` | `14` | ротация: каждый день новый файл, файлы старше N дней удаляются автоматически (при старте сервера и при смене даты). `0` хранит всё |
| `KillAttributionWindowSec` | `60` | если игрок умер без прямого убийцы (истёк кровью и т.п.), а за последние N секунд в него попадал игрок, убийство засчитывается этому игроку с пометкой «косвенно». `0` выключает |
| `DiscordKillsWebhook` | `""` | URL вебхука для убийств |
| `DiscordUsername` | `PvP Log` | имя бота в Discord |
| `HistorySize` | `50` | сколько последних событий хранится для `/pvplog` |

Сообщения в Discord отправляются пачками (до 5 событий раз в 2.5 секунды), чтобы не упереться в лимит Discord во время больших замесов.

## VPPAdminTools

После первого запуска в меню VPP **Permissions** появится право:

| Право | Что даёт |
|---|---|
| `PvPLog:ChatHistory` | чат-команда `/pvplog` |

Выдайте его нужной группе (например, Admins). Суперадмины получают его автоматически.

Чат-команда:
```
/pvplog        последние 5 PvP-событий
/pvplog 15     последние 15 (максимум 20)
```

Кто бросил гранату или поставил мину/ловушку, мод берёт из VPP (`Grenade_Base.GetActivator()`, `TrapBase.GetActivator()`), поэтому такие убийства тоже приписываются игроку.

## Формат логов

Текст (`PvP_2026-11-16.log`), координаты в формате `X, Y(высота), Z`:
```
[2026-11-16 21:43:12] HIT  | Bandit (76561198000000002) [4512.3, 312.1, 10234.8] -> Survivor (76561198000000001) [4590.1, 309.4, 10260.2] | M4-A1 (M4A1) | Bullet_556x45 | огнестрел | Торс | урон 42.0 HP, кровь 300.0, шок 20.0 | осталось 58.0 HP | 82.0 м
[2026-11-16 21:43:13] KILL | Убийца: Bandit (76561198000000002) [4512.3, 312.1, 10234.8] | Жертва: Survivor (76561198000000001) [4590.1, 309.4, 10260.2] | M4-A1 (M4A1) | Bullet_556x45 | огнестрел | Голова | 82.0 м
```

JSON (`PvP_2026-11-16.jsonl`), одно событие на строку:
```json
{"kind":"kill","time":"2026-11-16 21:43:13","killer":"Bandit","killerId":"76561198000000002","killerPos":[4512.3,312.1,10234.8],"victim":"Survivor","victimId":"76561198000000001","victimPos":[4590.1,309.4,10260.2],"weapon":"M4A1","weaponName":"M4-A1","ammo":"Bullet_556x45","method":"firearm","zone":"Head","distance":82.0,"indirect":false}
```
Поля попадания: `kind:"hit"`, `attacker/attackerId/attackerPos`, `victim/victimId/victimPos`, `weapon`, `weaponName`, `ammo`, `method`, `zone`, `damage`, `blood`, `shock`, `healthLeft`, `distance`.

## Что не логируется

- урон от зомби, животных, падений и самому себе (это не PvP);
- взрывчатка без отслеживания владельца (C4/IED): VPP запоминает только гранаты и ловушки;
- выстрелы по уже мёртвому телу.
