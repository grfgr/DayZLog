# Локальный сервер для теста PvPLog

Для Windows. Пути ниже даны для стандартной установки Steam, поправьте под свои.

## 1. Что поставить из Steam

1. **DayZ Server**: Steam → Библиотека → фильтр «Инструменты» → *DayZ Server*. Бесплатно, если у вас есть DayZ.
   Папка: `C:\Program Files (x86)\Steam\steamapps\common\DayZServer`
2. **DayZ Tools**: там же, в «Инструментах». Нужен только **Addon Builder**.
3. Подпишитесь в Мастерской на:
   - **Community Framework**: https://steamcommunity.com/sharedfiles/filedetails/?id=1559212036
   - **VPPAdminTools**: https://steamcommunity.com/sharedfiles/filedetails/?id=1828439124

   Запустите DayZ Launcher, чтобы моды скачались. Они окажутся в
   `C:\Program Files (x86)\Steam\steamapps\common\DayZ\!Workshop\` (папки `@CF` и `@VPPAdminTools`).

## 2. Моды на сервер

1. Скопируйте `@CF` и `@VPPAdminTools` из `DayZ\!Workshop\` в папку `DayZServer\`.
2. Скопируйте ключи: всё из `@CF\keys\` и `@VPPAdminTools\keys\` (файлы `*.bikey`) положите в `DayZServer\keys\`.

## 3. Сборка PvPLog в PBO (подробно)

### 3.1. Скачать мод с GitHub
1. Откройте в браузере https://github.com/grfgr/DayZLog
2. Слева вверху над списком файлов есть кнопка с названием ветки (обычно `main`). Нажмите её и выберите `claude/pvp-logging-mod-ugsq1y`.
3. Нажмите зелёную кнопку **Code** → **Download ZIP**.
4. Распакуйте архив, например в `C:\DayZMods\`. Получится
   `C:\DayZMods\DayZLog-claude-pvp-logging-mod-ugsq1y\PvPLog\`.
   В этой папке `PvPLog` должны лежать `config.cpp`, `mod.cpp`, `$PBOPREFIX$` и папка `scripts`. Это и есть исходник мода.

> Совет: включите показ расширений файлов. Проводник → **Вид** → **Показать** → **Расширения имён файлов**. Иначе дальше легко создать `start.bat.txt` вместо `start.bat`.

### 3.2. Папка мода на сервере
В папке сервера `C:\Program Files (x86)\Steam\steamapps\common\DayZServer\` создайте папку `@PvPLog`, а в ней папку `Addons`:
```
DayZServer\@PvPLog\Addons\
```

### 3.3. Addon Builder
1. Steam → **Библиотека** → в фильтре слева выберите **Инструменты** → **DayZ Tools** → **Играть** (Запустить).
2. Откроется лаунчер DayZ Tools. В нём нажмите **Addon Builder**.
3. В окне Addon Builder заполните:
   - **Addon source directory**: кнопка `...` → выберите `C:\DayZMods\DayZLog-claude-pvp-logging-mod-ugsq1y\PvPLog`;
   - **Destination directory**: кнопка `...` → выберите `...\DayZServer\@PvPLog\Addons`.
4. Галочки в главном окне:
   - **Binarize**: **снять**. Мод состоит только из скриптов, бинаризация не нужна и только мешает;
   - **Clear temp folder**: поставить;
   - **Sign**: не нужна.
5. Нажмите **Options**. В открывшемся окне:
   - **Addon prefix**: `PvPLog`;
   - **List of files to copy directly**: в конец строки допишите `;*.c;*.cpp`. Если строка пустая, впишите `*.c;*.cpp`;
   - нажмите **OK**.
6. Нажмите **Pack**. В конце внизу появится надпись об успешной сборке.
7. Проверьте: должен появиться файл `DayZServer\@PvPLog\Addons\PvPLog.pbo`.

**Если Addon Builder ругается** (например, требует диск P: или пишет ошибку о binarize): подойдёт любой другой упаковщик, например **PBO Manager**. Установите его, нажмите правой кнопкой по папке `PvPLog` → **PBO Manager → Pack into "PvPLog.pbo"** и положите полученный файл в `@PvPLog\Addons\`. Префикс он возьмёт из файла `$PBOPREFIX$`.

## 4. Настройка сервера (подробно)

### 4.1. serverDZ.cfg
1. Откройте `DayZServer\serverDZ.cfg`: правой кнопкой → **Открыть с помощью** → **Блокнот**.
2. Найдите эти строки и поменяйте значения (остальное не трогайте):
   ```
   hostname = "PvPLog test";      // название сервера
   password = "";                 // пароль на вход: пусто = без пароля
   passwordAdmin = "admin123";    // пароль RCon/админа игры
   verifySignatures = 2;          // оставить 2
   BattlEye = 1;                  // оставить 1
   ```
3. Добавьте новую строку **над** блоком `class Missions` (в любом месте, но не внутри фигурных скобок):
   ```
   vppDisablePassword = 1;
   ```
   Так VPP не будет спрашивать свой пароль. **На боевом сервере эту строку уберите.**
4. Внизу файла должно быть:
   ```
   class Missions
   {
       class DayZ
       {
           template = "dayzOffline.chernarusplus";
       };
   };
   ```
5. **Файл → Сохранить**.

### 4.2. Файл запуска start.bat
1. В папке `DayZServer` правой кнопкой → **Создать → Текстовый документ**.
2. Откройте его и вставьте (если Steam стоит не на диске C, поправьте путь во второй строке):
   ```bat
   @echo off
   cd /d "C:\Program Files (x86)\Steam\steamapps\common\DayZServer"
   start "" DayZServer_x64.exe -config=serverDZ.cfg -port=2302 -profiles=profiles -dologs -adminlog -netlog -freezecheck "-mod=@CF;@VPPAdminTools" "-servermod=@PvPLog"
   ```
3. **Файл → Сохранить как**: тип файла **Все файлы**, имя `start.bat`.
4. Старый `Новый текстовый документ.txt` удалите.

Что значит каждый параметр:
- `-profiles=profiles`: все логи и настройки модов будут в `DayZServer\profiles\`;
- `-mod=`: моды, которые нужны и серверу, и игроку (CF, VPP);
- `-servermod=`: моды только для сервера (наш PvPLog).

### 4.3. Первый запуск
1. Двойной клик по `start.bat`. Откроется консольное окно сервера. Подождите 1–3 минуты, пока в нём не появится строка вида `Players: 0`, а нагрузка не успокоится.
2. Закройте окно сервера крестиком. Это первый запуск: он нужен, чтобы VPP и PvPLog создали свои папки.
3. Проверьте, что появилось:
   - `DayZServer\profiles\PvPLog\settings.json`: **значит, PvPLog работает**;
   - `DayZServer\profiles\VPPAdminTools\`;
   - `DayZServer\profiles\script_<дата_время>.log`. Откройте его Блокнотом, нажмите Ctrl+F и найдите `PvPLog`. Должна быть строка `[PvPLog] started`.

**Если сервер закрывается сам** или показывает окно с ошибкой вроде `Can't compile "World" script module`, мод не скомпилировался. Пришлите последний `script_*.log`.

### 4.4. Права суперадмина в VPP
1. Узнайте свой Steam64 ID:
   - Steam → нажмите на свой ник вверху → **Профиль**;
   - правой кнопкой по пустому месту страницы → **Скопировать адрес страницы**;
   - если в адресе есть `/profiles/7656119xxxxxxxxxx`, это число и есть ID;
   - если там `/id/имя`, вставьте адрес на https://steamid.io и возьмите поле **steamID64**.
2. Откройте `DayZServer\profiles\VPPAdminTools\Permissions\SuperAdmins\SuperAdmins.txt` Блокнотом. Если файла нет, создайте его по этому пути.
3. Сотрите всё, что там есть, впишите свой ID одной строкой (17 цифр, без пробелов) и сохраните.

## 5. Запуск и подключение
1. Запустите `start.bat` и дождитесь загрузки сервера (1–3 минуты).
2. Запустите **DayZ Launcher** (обычный запуск DayZ из Steam).
3. Вкладка **Моды**: поставьте галочки у **Community Framework** и **VPPAdminTools**.
4. Вкладка **Серверы** → вверху **LAN**. Найдите там `PvPLog test` и подключитесь.
   Если сервера в LAN нет, внизу нажмите **Прямое подключение (Direct Connect)**: IP `127.0.0.1`, порт `2302`.
5. Если Windows спросит про доступ брандмауэра для DayZServer, разрешите.
6. В игре:
   - **Home** открывает меню VPP;
   - **End** включает и выключает режим админки.

## 6. Тест на манекене

Удобнее всего заспавнить всё **командами в чате** VPP. Открыть чат: **Enter**, вписать команду, ещё раз **Enter**.

1. Оружие в руки:
   ```
   /sph M4A1
   ```
2. Магазины в инвентарь (если в одежде нет места, они упадут на землю):
   ```
   /spi Mag_STANAG_30Rnd
   /spi Mag_STANAG_30Rnd
   ```
   Если не появились, кладите на землю: `/spg Mag_STANAG_30Rnd`.
3. Зарядите: откройте инвентарь (**Tab**) и перетащите магазин на оружие, или нажмите **R** с магазином в инвентаре.
4. Манекен. Он появится в метре перед вами:
   ```
   /spg SurvivorM_Mirek
   ```
5. Отойдите от него на 20–50 метров.
6. Стреляйте: сначала в ногу, потом в торс, потом в голову.
7. Проверьте результаты:
   - **Уведомление VPP**: после смерти манекена справа вверху появится всплывашка «PvP: убийство»;
   - **Чат**: введите `/pvplog`, придут последние события;
   - **Файл лога**: сверните игру (Alt+Tab) и откройте `DayZServer\profiles\PvPLog\logs\PvP_<сегодняшняя дата>.log`. Там должны быть строки `HIT` с зоной попадания и `KILL` с координатами обоих;
   - **JSON**: рядом лежит `PvP_<дата>.jsonl` с теми же событиями;
   - **Права**: в меню VPP (**Home**) → **Permissions** выберите группу и найдите в списке `PvPLog:KillAlerts`, `PvPLog:HitAlerts`, `PvPLog:ChatHistory`.

Ещё тесты:
- **Рукопашка**: уберите оружие (**X**), заспавните нового манекена и ударьте его. В логе: `Кулаки`, «ближний бой»;
- **Нож**: `/sph KitchenKnife` → ударьте;
- **Граната**: `/sph M67Grenade`, выдерните чеку (**ЛКМ** зажать) и бросьте к манекену. В логе способ «взрыв» и ваш ник;
- **Другое оружие**: `/sph Mosin9130` + `/spi Ammo_762x54`.

В логе манекен называется `Bot (SurvivorM_Mirek)` и у него нет Steam ID. С живым игроком там будут ник и ID.

## 7. Discord
1. В Discord: правой кнопкой по каналу → **Настроить канал** → **Интеграция** → **Вебхуки** → **Новый вебхук** → **Копировать URL вебхука**.
2. **Выключите сервер** (закройте его окно). Если править файл при работающем сервере, тот перезапишет его при выключении.
3. Откройте `DayZServer\profiles\PvPLog\settings.json` Блокнотом и вставьте URL в кавычки:
   ```json
   "DiscordKillsWebhook": "https://discord.com/api/webhooks/123.../abc...",
   "DiscordHitsWebhook": "https://discord.com/api/webhooks/123.../abc...",
   ```
   Для теста можно указать один и тот же URL в оба поля. Не удаляйте запятые в конце строк.
4. Сохраните, запустите сервер, убейте манекена. Сообщение придёт в канал за 2–3 секунды.

## 8. Настоящий PvP-тест
Второй клиент на том же ПК под тем же Steam-аккаунтом не запустить, поэтому нужен второй игрок (друг):
- **в одной домашней сети**: друг подключается к вашему локальному IP (`ipconfig` → IPv4, например `192.168.1.10`), порт `2302`;
- **через интернет**: на роутере пробросьте порты `2302–2305 UDP` и `27016 UDP` на ваш ПК. Друг подключается к вашему внешнему IP.

Другу нужны те же моды: CF и VPPAdminTools. PvPLog ему ставить не нужно.

## 9. Если что-то не работает
Пришлите:
- последний `DayZServer\profiles\script_*.log`;
- `DayZServer\profiles\PvPLog\logs\PvP_<дата>.log`, если он появился;
- что делали и что ожидали увидеть.
